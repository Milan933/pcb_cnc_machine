# Precision mechanical CAD research basis

Retrieved 2026-10-07. These sources were used to synthesize practical agent instructions. They are not copied into the skill, and their application must be adapted to the selected material, process, supplier, and inspection method.

| Topic | Reference | Practical use in this skill |
| --- | --- | --- |
| GD&T design language | [ASME Y14.5](https://www.asme.org/codes-standards/find-codes-standards/dimensioning-and-tolerancing) | Treat datum references, form/orientation/location controls, profile, position, modifiers, and interpretation as functional product definition rather than drawing decoration. |
| Datum systems | [ISO 5459:2024](https://www.iso.org/cms/%20render/live/en/sites/isoorg/contents/data/standard/08/78/87855.html?browse=ics) and [NIST datum-system model](https://nvlpubs.nist.gov/nistpubs/jres/104/4/html/j44mac.htm) | Establish datum features and reference systems from functional location and verification, not arbitrary face chains. |
| Fits and limits | [ISO 286-1:2010](https://www.iso.org/standard/45975.html) and [ISO limits and fits catalogue](https://www.iso.org/ics/17.040.10/x/) | Select hole/shaft tolerance classes and fit intent deliberately; do not confuse nominal size with allowable variation. |
| General tolerancing | [ISO 2768 project page](https://www.iso.org/standard/85741.html) | Use general tolerances as controlled defaults only when the applicable edition, process, and feature class are appropriate; critical features need individual requirements. |
| Metrology and GD&T communication | [NIST dimensional measurement reference](https://www.nist.gov/publications/information-required-dimensional-measurement) and [NIST GD&T fundamentals](https://www.nist.gov/publications/fundamentals-geometric-dimensioning-and-tolerancing-part-ii) | Define how critical dimensions and geometric controls will be measured and traced. |
| Parametric and top-down CAD | [Autodesk top-down design](https://help.autodesk.com/cloudhelp/2023/ENU/Inventor-Help/files/GUID-3EDEE28E-2884-4507-8DA7-0AE52977A5ED.htm), [Autodesk assembly overview](https://help.autodesk.com/view/fusion360/ENU/?contextId=ASM-OVERVIEW), and [Onshape mates](https://cad.onshape.com/help/Content/Assembly/mates.htm) | Use master layouts for coupled geometry, bottom-up components for standard parts, explicit assembly relationships, and intentional degrees of freedom. |
| Bearing and linear-motion integration | [SKF bearing principles](https://cdn.skfmediahub.skf.com/api/public/0901d19680495562/pdf_preview_medium/0901d19680495562_pdf_preview_medium.pdf) and [THK guide rigidity](https://www.thk.com/eu/en/products/lm_guide/selection/0008/) | Separate radial/axial reactions, locating/floating supports, preload, guide moment capacity, and mounting-surface stiffness. |
| Shaft couplings | [Lovejoy engineering data](https://www.lovejoy-inc.com/products/engineering-data/) and [Lovejoy coupling handbook](https://www.lovejoy-inc.com/resources/the-lovejoy-coupling-handbook/) | Select couplers for torque, speed, bore, misalignment, axial travel, torsional behavior, and reaction loads; alignment is still required. |
| Fasteners in polymers | [SPIROL inserts design guide](https://www.spirol.com/assets/files/ins-threaded-inserts-design-guide-us.pdf) and [SPIROL insert-hole guidance](https://my.spirol.com/resources/white-papers/how-to-design-the-proper-hole-for-heat-ultrasonic-inserts/) | Treat insert hole size, depth, boss/wall, mating clearance, installation, and material/process as coupled design variables requiring testing. |
| Machining design | [Protolabs CNC machining toolkit](https://www.protolabs.com/resources/design-for-machining-toolkit/), [machining design for speed](https://www.protolabs.com/en-gb/resources/guides-and-trend-reports/cnc-machining-designing-for-speed/), and [CNC hole guidance](https://www.protolabs.com/en-gb/resources/blog/cnc-hole-design-through-blind-tapped-and-more/) | Account for tool diameter, corner radii, reach, deep/narrow features, setups, workholding, tolerances, and datum transfer. |
| Additive design | [Prusa modeling guidance](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135), [Prusa support guidance](https://help.prusa3d.com/article/support-material_1698?product=cw1), and [Protolabs printing tolerances](https://www.protolabs.com/resources/design-tips/3d-printing-tolerances/) | Relate orientation, anisotropy, support, shrinkage, fit clearance, walls, and process calibration to functional geometry. |
| Verification and review | [NASA Systems Engineering Handbook](https://www.nasa.gov/wp-content/uploads/2018/09/nasa_systems_engineering_handbook_0.pdf) | Plan evidence from requirements and keep analysis, inspection, demonstration, test, fit-check, and human review distinct. |
| build123d implementation | [build123d key concepts](https://build123d.readthedocs.io/en/stable/key_concepts.html), [design tutorial](https://build123d.readthedocs.io/en/latest/tutorial_design.html), and [import/export](https://build123d.readthedocs.io/en/stable/import_export.html) | Use explicit planes/locations, stable reference geometry, deterministic transforms, reusable builders, and explicit STEP/STL settings without making API syntax the engineering method. |
