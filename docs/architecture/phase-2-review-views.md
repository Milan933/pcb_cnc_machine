# Phase 2 review views

These are architecture schematics, not manufacturing drawings. They show the
B skeleton's envelopes and reference lines; the exact values remain in
`cad/parameters.py`. The [SVG review sheet](phase-2-skeleton-views.svg) is
tracked as a source review artifact. The temporary STEP/STL exports from the
spike provide a viewable 3D compound without publishing manufacturing files.

The sheet contains front, side, top, pseudo-isometric, and force-loop views.
It intentionally omits wall thickness, holes, fasteners, cosmetic features,
and unselected hardware geometry.
