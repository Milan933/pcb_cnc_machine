# Phase 2 review views

These are architecture schematics, not manufacturing drawings. The tracked
sheet shows the original B-oriented skeleton envelopes and reference lines;
the exact values remain in `cad/parameters.py`. The focused Phase 2A A/B
review volumes are generated by `tools.run_phase2a_study` and are intentionally
not baked into the SVG. The [SVG review sheet](phase-2-skeleton-views.svg) is
tracked as a source review artifact. Temporary STEP/STL exports from either
spike provide a viewable 3D compound without publishing manufacturing files.

The sheet contains front, side, top, pseudo-isometric, and force-loop views.
It intentionally omits wall thickness, holes, fasteners, cosmetic features,
and unselected hardware geometry.
